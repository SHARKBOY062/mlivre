🧩 PARTE 1 — CORRIGIR O VALOR
❌ REMOVER VALOR FIXO

Localize no código onde aparece:

49.70


ou

R$ 49,70


E remova completamente.

✅ DEFINIR VALORES CORRETOS NO JS

No arquivo script.js:

const valorBase = 180.00;
const valorSeguro = 43.87;

✅ FUNÇÃO DE CÁLCULO

Criar ou corrigir:

function calcularTotal() {
  const comSeguro = document.getElementById("comSeguro").checked;

  let total = valorBase;

  if (comSeguro) {
    total += valorSeguro;
  }

  return total;
}

✅ ATUALIZAR NA TELA FINAL

Antes de mostrar o resultado:

const total = calcularTotal();

document.getElementById("valorFinal").innerText =
  "R$ " + total.toFixed(2).replace(".", ",");

📌 No HTML:

Substituir o total por:

<span id="valorFinal"></span>

⚙️ PARTE 3 — CONTROLE DO FLUXO (JS)

NO script.js:
document.getElementById("btnFinalizar").addEventListener("click", function() {

  // Mostrar loading
  document.getElementById("loadingTela").style.display = "flex";

  // Esconder conteúdo atual
  document.getElementById("conteudoPrincipal").style.display = "none";

  // Simular processamento
  setTimeout(() => {

    document.getElementById("loadingTela").style.display = "none";

    mostrarResultadoFinal();

  }, 12000); // 12 segundos
});

FUNÇÃO FINAL
function mostrarResultadoFinal() {

  const total = calcularTotal();

  document.getElementById("valorFinal").innerText =
    "R$ " + total.toFixed(2).replace(".", ",");

  document.getElementById("telaResultado").style.display = "block";
}
