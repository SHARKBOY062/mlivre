Atualize o sistema de checkout conforme as instruções abaixo.

🎯 OBJETIVO

Após o usuário clicar em:

“Confirmar pagamento e enviar dados”

Deve:

1️⃣ Esconder a tela atual
2️⃣ Mostrar nova tela de pagamento via PIX
3️⃣ Exibir QR Code
4️⃣ Mostrar valor total correto
5️⃣ Corrigir botão que está cortando texto

🧩 PARTE 1 — CORRIGIR BOTÃO CORTADO
❌ Problema:

O texto não está cabendo no botão.

✅ Solução CSS:

Substituir estilo do botão por:

.botao-confirmar {
  width: 100%;
  padding: 16px;
  font-size: 16px;
  font-weight: 600;
  border-radius: 8px;
  white-space: normal;
  text-align: center;
}

✅ Atualizar texto para algo mais limpo:

Trocar:

CONFIRMAR PAGAMENTO E ENVIAR DADOS


Por:

Confirmar e Gerar PIX

🧾 PARTE 2 — CRIAR TELA DE PIX
📄 1️⃣ Criar nova div no HTML (antes de </body>):
<div id="telaPix" class="tela-pix" style="display:none;">
  <div class="pix-box">
    <h2>Pagamento via PIX</h2>
    <p>Escaneie o QR Code abaixo para concluir</p>

    <img src="https://api.qrserver.com/v1/create-qr-code/?size=200x200&data=PagamentoPIX" />

    <h3>Total: <span id="valorPix"></span></h3>

    <p>Aguardando confirmação de pagamento...</p>
  </div>
</div>

🎨 PARTE 3 — ESTILO DA TELA PIX

Adicionar no CSS:

.tela-pix {
  position: fixed;
  top: 0;
  left: 0;
  width: 100%;
  height: 100%;
  background: #ffffff;
  display: flex;
  justify-content: center;
  align-items: center;
  z-index: 9999;
}

.pix-box {
  text-align: center;
  padding: 30px;
  border-radius: 12px;
  box-shadow: 0 10px 30px rgba(0,0,0,0.1);
  max-width: 400px;
  width: 90%;
}

⚙️ PARTE 4 — FUNCIONALIDADE JS

No script.js, adicionar:

document.getElementById("btnFinalizar").addEventListener("click", function() {

  // Esconde tela atual
  document.getElementById("conteudoPrincipal").style.display = "none";

  // Atualiza valor no PIX
  const total = calcularTotal();
  document.getElementById("valorPix").innerText =
    "R$ " + total.toFixed(2).replace(".", ",");

  // Mostra tela PIX
  document.getElementById("telaPix").style.display = "flex";

});

1️⃣ Usuário escolhe seguro
2️⃣ Valor atualiza corretamente
3️⃣ Clica em “Confirmar e Gerar PIX”
4️⃣ Some a tela atual
5️⃣ Abre tela com QR Code
6️⃣ Mostra valor correto
